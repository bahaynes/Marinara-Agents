# Wasteland SPECIAL

A data-only Game Mode ruleset inspired by Fallout's SPECIAL system with tactical d20 combat.

## Features

- **SPECIAL Stats & Skills**: Strength, Perception, Endurance, Charisma, Intelligence, Agility, and Luck stats paired with 14 skills on a d20 + modifier ladder.
- **5e Difficulty Ladder & Aliases**: Calibrated difficulty scale (Very Easy 5 to Nearly Impossible 30; Medium 15) with aliases mapping common tabletop skill checks (e.g. Insight → Speech, Spot/Search → Survival).
- **Survival Mechanics**: Hit points, radiation damage track, and multiple currencies (`cap` caps, NCR dollars, legion denarii).
- **Armory & Items**: Weapon categories with ammunition tags, magazine clips, usable Stimpaks, and charged Doctor's bags.
- **Tactical Combat**: Full tactical battle board integration with range brackets (normal and long), reach, ammo tracking, and cover.

## Installation & Setup

1. Install **Wasteland SPECIAL** from the Agents catalog in Marinara Engine.
2. In Game Mode setup, choose **Wasteland SPECIAL** under Rules when creating a new game.
